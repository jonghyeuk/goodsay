# 디자인 노트

## 방향

"작은 온라인 잡지에서 나에게 온 편지 한 장을 펼치는 느낌"을 목표로 합니다. 무거운 점술 이미지나 공포·불안을 유도하는 판매 표현을 사용하지 않습니다.

- 종이 느낌의 밝은 바탕, 짙은 녹색 본문·버튼, 테라코타 포인트
- 한국어 명조 제목과 산세리프 본문, 충분한 행간과 여백
- 본문을 사진 위에 쌓지 않고, 사진과 읽을 영역을 구분
- 오늘의 글 → 주제별 글 → 가벼운 체험 → 해설 샘플 순으로 탐색
- 모바일에서 명확한 하단 내비게이션, 문장 단위의 버튼명
- 프리미엄 샘플과 무료 문답형 결과를 실제 판매/실제 고객 결과와 구분

## 참고한 공개 사이트

아래 사이트의 구조·분위기를 참고했으며 로고·화면·카피·코드를 복제하지 않았습니다.

1. [Aesop](https://www.aesop.com/) — 절제된 편집 구성, 여백과 제품/설명문의 균형
2. [CHANI](https://www.chani.com/) — 무료 읽을거리와 심화 개인 상품의 콘텐츠 계층
3. [Headspace](https://www.headspace.com/) — 일상 언어로 부담을 낮추는 안내와 작은 시작
