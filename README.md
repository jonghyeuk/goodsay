# 오늘 한 장 · Goodsay

좋은글을 읽고, 네 가지 질문으로 마음을 돌아보고, 문장을 보관하고 나누는 한국어 모바일 웹입니다. 가입이나 앱 설치 없이 이용합니다.

**처음 운영하신다면 [운영자 사용 설명서](docs/operations.md)부터 읽어주세요.** 방문자 사용법, 좋은글 추가 양식, 현재 매출이 발생하지 않는 이유와 판매 연결 작업을 구분해 정리했습니다.

## 현재 구현 상태

**실제 이용 가능한 기능**

- 직접 작성한 좋은글 24편, 한국 시간 자정 기준 오늘의 글 자동 선택
- 주제별 탐색·본문 검색·글 상세·연관 글
- 브라우저 책갈피 보관함·삭제·재열람
- 네 문항 기반 성향 체험과 동의한 경우에만 결과 유형 저장
- 개인정보 없는 공유 카드 미리보기·PNG 저장·지원 기기에서 네이티브 공유
- 공개 글 링크 복사·지원 브라우저에서 한국어 읽어주기
- 가상 인물의 전체 해설 샘플 8장·인쇄/PDF 저장
- 모바일 하단 내비게이션, 키보드 조작, 줄어든 모션 설정 반영

**아직 제공하지 않는 기능**

- 실제 결제, 결제 검증·웹훅, 환불, 판매자 고객지원
- 연락처 인증, 실제 주문 복구, 서버 구매 내역 저장
- 사주/점성술 계산, AI 개인 해설 생성

9,900원은 **출시 제안가**입니다. 모든 구매 화면에 실제 결제가 제공되지 않음을 표시하며 결제 버튼은 비활성입니다. 무료 체험은 답변 기반 자기성찰 콘텐츠로, 사주 또는 전문 심리 진단으로 표시하지 않습니다. 서버 API도 미연결 구매 요청을 `503 SERVICE_NOT_CONFIGURED`로 차단합니다. 실제 개인정보를 시험 입력하지 않아도 됩니다.

## 실행

Node.js 22 이상 권장. 서비스 실행에는 외부 런타임 패키지가 필요하지 않습니다.

```bash
npm run dev
```

기본 주소는 `http://localhost:5173`이며 `PORT` 환경변수로 변경할 수 있습니다. 클라우드 관리 미리보기에서는 해당 환경이 제공하는 미리보기 도구를 사용합니다.

## 검사 및 빌드

```bash
npm ci
npm run check
```

`check`는 JavaScript 문법, 날짜·저장·공유 데이터, HTTP/API 차단 동작, DOM 기반 사용자 흐름을 검사하고 `dist/`를 생성합니다. `happy-dom`은 테스트용 개발 의존성으로만 사용합니다. 실제 브라우저의 렌더링·화면 크롭·기기별 이미지 다운로드/음성 동작을 검사하는 테스트는 아닙니다.

```bash
npm run build
SITE_URL=https://your-real-domain.example npm run build
```

실제 도메인을 `SITE_URL`로 전달하면 canonical/og:url이 추가됩니다. 임의의 서비스 주소를 미리 선언하지 않습니다. `dist/`를 정적 호스팅에 배포할 수 있으며 하위 경로에서도 동작하도록 상대 경로와 해시 라우팅을 사용합니다. 해시별 콘텐츠의 검색 최적화는 추후 개별 서버/정적 URL로 확장할 항목입니다.

## Firebase Hosting (지정된 배포 대상)

`education-news-site` 프로젝트의 동일한 Hosting 사이트로 배포하도록 구성되어 있습니다. [Firebase 연결·배포 안내](docs/firebase.md)를 참고하세요. 인증 시크릿 등록 후 main 변경을 자동 배포하는 워크플로가 포함됩니다. 배포 설정만으로 실제 배포 성공을 의미하지 않습니다.

## GitHub Pages (대체 배포 경로)

자동으로 공개 배포하지 않습니다. 검토 후 저장소 **Settings → Pages → Source: GitHub Actions**를 설정하고 **Actions → Publish Goodsay to GitHub Pages → Run workflow**를 실행하면 됩니다. CI는 `main` 변경과 PR에서 검사한 정적 결과를 artifact로도 남깁니다.

## 데이터와 외부 자원

개인 답변을 서버로 보내지 않습니다. 로컬 저장소에는 허용된 글 ID와 동의해 저장한 유형 ID만 남습니다. 보관함 비우기로 삭제합니다. 공유 URL은 쿼리 파라미터를 지우고 공개 글 ID만 포함합니다. Google Fonts는 선택적 외부 글꼴이며 차단되어도 시스템 글꼴로 이용할 수 있습니다. 사진은 `assets/`에 포함했습니다. 분석·광고 추적기는 설치하지 않았습니다.
